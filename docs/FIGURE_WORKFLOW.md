# CLOP-DiT Figure Generation Workflow

This document describes the complete figure generation, validation, and delivery pipeline for the CLOP-DiT article.

## Pipeline Overview

```
Training → Evaluation → Visualization → VCD Check → Article Delivery → LaTeX Compilation
```

## 1. Training Pipeline (produces raw data)

- **CLOP training**: Produces `models/checkpoints/clop_history.json`
- **DiT training**: Produces `models/checkpoints/dit_history.json`
- **Cached latents**: `data/cached_latents_v5.2/*.npy`

## 2. Evaluation Pipeline (produces metrics JSONs)

Entry points:
- `scripts/06_evaluate.py` — comprehensive evaluation
- `scripts/10_full_pipeline.py` — full pipeline with evaluation stage

Outputs:
- `results/archive/v5_final/final_evaluation.json` — core metrics (KNN, steering, FD, etc.)
- `results/expression_metrics.json` — per-gene correlations
- `results/bootstrap_cis.json` — bootstrap confidence intervals
- `results/benchmark_report.json` — multi-method benchmark
- `results/downstream/clustering_alignment.json` — ARI, NMI, mixing
- `results/downstream/classifier_alignment.json` — accuracy, F1, AUC
- `results/downstream/de_concordance.json` — logFC correlation, Jaccard
- `results/robustness/bioval_*/metrics_summary.json` — cross-dataset validation
- `results/ablations/*/summary.json` — ablation experiments
- `results/rare_cell_augmentation/augmentation_results.json`
- `results/ood_evaluation/ood_results.json`

## 4. VCD (Visual Conflict Detection)

Every figure is automatically checked by VCD during save via `save_with_vcd()` in `src/visualization/style.py`.

VCD is a 30-pass, 4-layer detection system in `scripts/vcd/`:
- Layer 1 (Subplot): Legend/colorbar checks
- Layer 2 (Figure): Text overlaps, truncation, label density
- Layer 3 (Perceptual): WCAG contrast, CVD safety
- Layer 4 (Semantic): Overplotting, log-scale sanity

Manual VCD check:
```python
from src.visualization.style import run_vcd_check
run_vcd_check(fig, label="my_panel")
```

## 5. Article Delivery

```bash
python -m src.visualization.article_delivery          # verify + create symlinks
python -m src.visualization.article_delivery --check-only  # verify only
```

Creates symlinks in `articles/figures/` pointing to `results/figures/`.
The canonical list of 17 article figures is in `src/visualization/article_delivery.py`.

## 6. LaTeX Compilation

```bash
cd articles && latexmk -pdf clop_dit_biology.tex
```

## 7. Legacy (NOT USED)

The `arch-figure/` directory contains a Nuxt.js + Puppeteer frontend that was the original architecture figure approach. This is now fully replaced by `scripts/generate_architecture_figure.py` (pure matplotlib). The frontend is dead code.

## Style Constants

All font sizes and colors are centralized in `src/visualization/style.py`:
- `FONT_TITLE = 11` (subplot titles)
- `FONT_LABEL = 10` (axis labels)
- `FONT_TICK = 10` (tick labels)
- `FONT_TICK_DENSE = 8` (dense heatmap ticks)
- `FONT_LEGEND = 10` (standard legend)
- `FONT_ANNOTATION = 8` (annotations)
- `FONT_SMALL = 7` (minimum readable)
- Panel labels: 12pt bold via `add_panel_label()`
