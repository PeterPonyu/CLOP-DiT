4. DiT ARCHITECTURE & EXPECTED INPUT FORMAT
═══════════════════════════════════════════════════════════════════════════════

From src/architecture/dit.py:

Class: DiT1D (1D Diffusion Transformer)
- Input latent dimension: 512 (from scGPT cell embeddings)
- Timestep embedding: Sinusoidal(t ∈ [0,1]) → 256-dim → mlp → hidden_dim
- Condition embedding: Linear(512) → hidden_dim → modulation
- Architecture: N = 12 DiTBlock (Transformer layers with AdaLN-Zero)
- Output: Velocity prediction v(z_t, t, c) for flow matching
- Conditioning: Injected via adaptive layernorm scaling/shifting

Flow Matching Formulation:
  z_t = (1-t)*z_0 + t*z_1,  z_0 ~ N(0,I), z_1 = real cell embedding
  v_target = z_1 - z_0
  Loss = MSE(v_pred, v_target)
  → Trains model to predict velocity field

Condition Input Format (for DiT):
  - Source: projected_text.npy from CLOP pipeline (167245 × 512)
  - Mapping: text_group_ids_dedup.npy maps each cell to its condition vector
  - Shape per training step: (batch_size, 512)
  - Example: For batch of 1024 cells, condition shape = (1024, 512)

Classifier-Free Guidance Support:
  - ConditionEmbedder has dropout_prob = 0.1 by default
  - 10% of training batches drop condition (replace with learned null token)
  - Enables guidance strength control during generation (cfg_scale > 1.0)
