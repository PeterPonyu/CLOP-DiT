## Top 5 Blocker / High-Severity Findings

1. **Unresolved `??` LaTeX cross-references in rebuttal and cover letter** (rebuttal pp. 4, 8, 9, 10; cover letter p. 2). Literal `??` appears inline for Figure and Table references (confusion heatmap, 6-panel boxplot, Table 6/8, Figure 9). Reviewers will see `Figure ??` — high embarrassment cost. Fix all `\ref{}` labels before resubmission.

2. **ZCA ablation table proto_acc column mismatch** (rebuttal p.11). Rebuttal shows `proto_acc = 0.999 / 1.000 / 0.998`; manuscript Table 6 shows `Proto Acc (%) = 76.17 / 76.03 / 75.42`. Numerical/units contradiction on a headline reviewer-facing table. Rebuttal column likely reports a different metric (positive-pair accuracy?) or percentages dropped. Fix header or values.

3. **Cerebellum inhibitory-interneuron value disagrees three ways** (rebuttal p. 9 caption `0.045` / bar-chart `0.03` / manuscript prose `0.00`). Visually inconsistent result on the flagship OOD failure mode — reviewer will notice. Pick one canonical number and propagate.

4. **"Testis" vs "fetal gonadal (adrenal + Leydig)" labeling inconsistency** (rebuttal p.8 table, manuscript Table 8 row labeled "Testis / fetal gonadal"). Mixing anatomical labels on the flagship OOD tissue harms reviewer trust. Standardise to "fetal gonadal (adrenal + Leydig)".

5. **r_var = 0.988 (pooled) vs near-zero (per-dataset) conflation risk** (rebuttal p.5, Comment 2.8 vs Comment 2.9). The rebuttal cites `r_var = 0.988` without clarifying it is the pooled within-type statistic (distinct from the per-dataset cross-dataset r_var values in Table 4, which are ≈ 0). Reviewer 2 may read Comment 2.9 as contradicting Comment 2.8. Add explicit parenthetical distinguishing the two.
